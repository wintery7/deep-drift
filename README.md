# DEEP DRIFT

*Drift together, in silence.* — 같은 바다에서, 각자의 속도로.

해파리가 되어 심해를 유영하는 브라우저 기반 3D 멀티플레이 힐링 공간입니다.

## 실행

```bash
npm install
```

로컬에서 실행 (서버와 클라이언트를 한 번에):

```bash
npm run dev
```

→ http://localhost:5173 (게임 서버는 `:2567`). 탭을 두 개 열면 서로의 해파리가 보입니다.
Windows에서는 `start.bat`을 더블클릭하면 설치·실행·브라우저 열기까지 한 번에 됩니다.
창을 닫거나 Ctrl+C를 누르면 함께 종료됩니다.

배포 (서버가 빌드된 클라이언트까지 한 포트로 서빙):

```bash
npm run play
```

→ http://localhost:2567 · 포트는 `PORT`, 별도 게임 서버 주소는 빌드 시 `VITE_SERVER_URL`로 지정합니다.

Docker (WebSocket을 지원하는 호스팅이면 어디든 올릴 수 있습니다):

```bash
docker build -t deep-drift .
```

```bash
docker run -p 2567:2567 deep-drift
```

## 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 전진 / 좌 / 후진 / 우 |
| Space / Shift | 상승 / 하강 |
| E | 빛으로 인사 |
| 마우스 드래그 | 둘러보기 |
| Esc | 설정 · 일시정지 |

## 구조

```
shared/world.ts          클라이언트·서버 공용 월드 정의 (경계, 지형 높이, 메시지 형식)
server/src/
  index.ts               Express + Colyseus 서버
  OceanRoom.ts           방(최대 8명), 입장/퇴장/재접속, 이동 검증
  OceanState.ts          동기화 스키마 (위치·방향·외형·연결 상태)
client/src/
  game/                  상태 저장소, 입력, 런타임 값, 입장/퇴장 동작
  net/network.ts         Colyseus 연결, 재접속, 원격 스냅샷 버퍼
  audio/AudioEngine.ts   Web Audio 절차적 사운드 (환경음·물방울·고래·공간 음향)
  scene/                 심해 환경, 생명체, 해파리 셰이더, 플레이어/카메라, 원격 플레이어 보간
  ui/                    메인 메뉴, HUD, 설정
```

## 함께 있는 방식

- **빛으로 인사**: E를 누르면 해파리가 빛나고, 같은 바다의 다른 사람에게도 보입니다.
- **교감**: 다른 해파리 곁에 머물면 서로 은은히 밝아지고, 맥동이 맞춰지며, 둘 사이에 빛의 실이 이어집니다. 멀어지면 조용히 사라집니다.
- **초대**: HUD의 `초대`를 누르면 초대용 바다로 옮기고 링크(`?sea=...`)를 복사합니다. 그 링크로 들어온 사람끼리만 만납니다.
- **자라는 꼬리빛**: 바다 곳곳의 빛 플랑크톤을 지나가며 머금으면 촉수가 길어지고, 지나간 자리에 남는 꼬리빛도 길어집니다. 누군가와 함께 다니거나 뒤따라 유영하면 더 빨리 자랍니다. 줄어들지 않고 이 브라우저에 저장되며, 숫자나 순위는 표시하지 않습니다. 플랑크톤 배치는 모두에게 같지만 머금은 상태는 각자에게만 반영되어 나눠 가질 필요가 없습니다.
- **행렬**: 누군가의 뒤를 따라 유영하면 앞 해파리의 꼬리빛 위를 지나며 빛의 실로 이어집니다.
- **익명 이름**: 처음 오면 "느린 등불" 같은 이름이 자동으로 붙고, 메뉴에서 다시 뽑을 수 있습니다. 직접 입력은 받지 않고 정해진 단어 목록(`shared/names.ts`)의 조합만 쓰며, 서버는 번호만 검증합니다. 다른 해파리에게 가까이 가면 이름이 은은하게 떠오릅니다.
- **쉬는 중**: 일시정지하거나 다른 탭으로 가 있으면 다른 사람에게는 해파리가 조금 가라앉아 천천히 맥동하고, 이름 아래에 "쉬는 중"이 보입니다.
- **입장·퇴장 알림**: 누군가 들어오거나 돌아가면 이름과 함께 화면 아래에 조용히 한 번 알려 줍니다.
- **잠든 빛**: 바다 가운데에서 등불을 따라가면 거대한 고대 해파리가 잠들어 있습니다. 혼자 인사하면 뒤척이기만 하고, 두 명 이상이 8초 안에 곁에서 함께 인사(E)하면 60초 동안 깨어나 바다 전체가 환해집니다. 깨어 있는 동안 곁에 있으면 꼬리빛이 자랍니다. 혼자 온 사람도 볼 수 있도록 6분마다 스스로 30초간 눈을 뜹니다. 깨어나는 판정은 서버가 해서 같은 바다의 모두가 같은 순간을 봅니다.
- **노래하는 산호**: 다섯 군데에 여섯 개씩 모인 빛나는 관을 스치면 음이 하나 울립니다. 곁에서 인사하면 여섯 관이 차례로 울립니다. 어떤 순서로 울려도 어울리는 음계라서 아무렇게나 쳐도 듣기 좋고, 다른 사람이 울린 음도 그 자리에서 들려 함께 울리면 화음이 됩니다.
- **반응하는 환경**: 지나가면 산호가 밝아지고 물고기 떼가 비켜 갑니다.
- 메뉴에는 지금 바다에 있는 해파리 수가 보입니다 (`GET /stats`).

## 메모

- 해파리·산호·고래·사운드는 모두 코드로 생성합니다 (외부 GLB·음원 파일 없음).
- 해저 동굴(`client/src/scene/cave.ts`, `Cave.tsx`)은 바다 중심에서 등불 산호를 따라가면 나옵니다. 메시와 충돌 판정이 같은 형태 함수를 쓰며, 충돌은 클라이언트에서만 처리합니다.
- 서버는 물리 시뮬레이션을 하지 않고, 클라이언트가 보낸 위치의 형식·빈도·이동 거리·월드 범위만 검증합니다.
- 연결이 끊긴 사용자는 12초 동안 흐려진 채 남아 있다가 제거되며, 그 안에 돌아오면(새로고침 포함) 같은 자리로 복귀합니다.
- `?capture`를 붙여 개발 서버를 열면 캔버스를 이미지로 추출할 수 있습니다 (`preserveDrawingBuffer`).
